A repair pipeline with a visible chain of custody.

Every issue moves through a controlled sequence: ingestion, repository understanding, agent reasoning, isolated validation, and a reviewable GitHub change.

03 / REASON

04 / VERIFY
✓

Docker + Pull Request

Tests run in isolation. Only validated patches can reach GitHub.
